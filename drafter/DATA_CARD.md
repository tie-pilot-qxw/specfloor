# Qwen3-4B PerfectBlend DeepSpec Rollout

The training corpus of the prefix-attention drafter: Open PerfectBlend
(`mlabonne/open-perfectblend`, revision `af60f3c18201652a83a93f46fcfee1b646ba3df7`)
with every assistant turn regenerated by Qwen3-4B.  The regenerated shards are
published as a Hugging Face dataset *(withheld for review)*;
`README.md` gives the commands that turn them into the training file.

## Data construction

- Canonical filtered corpus: 1,420,906 conversations.
- Split: seed 42, 95% train / 5% eval (1,349,860 / 71,046).
- The original assistant messages are discarded. Every assistant turn is
  regenerated in order, and each generated answer is included in the context
  for subsequent turns in the same conversation.
- Generator: `Qwen/Qwen3-4B`, with thinking disabled.
- Sampling: temperature 0.7, top-p 0.8, top-k 20, min-p 0.
- Maximum generated tokens per assistant turn: 4,096.
- No deduplication is applied.
- Canonical source content SHA256:
  `9d1376be67ae4c4708145d6939c4d8d49e467e5c4b78773fce633b81ea256613`.

## Schema

Each line is one JSON object:

```json
{
  "id": 123,
  "conversations": [
    {"role": "user", "content": "..."},
    {"role": "assistant", "content": "..."}
  ],
  "status": "success"
}
```

`id` is the global ID from the canonical filtered dataset and is used for
exact-ID resume and coverage validation.

## Integrity of the snapshot used for training

The snapshot contains 128 of 128 shards, 1,349,860 unique
conversations, and 1,790,166 generated assistant turns. Exact validation
against the fixed-revision, seed-42 source split found no missing or duplicate
IDs, changed user turns, failed statuses, empty assistant responses, malformed
records, or role-order mismatches.

`merged.jsonl` is the validated shard concatenation. The formal online-hidden
trainer consumes `online_train.jsonl`, produced with the Qwen chat template,
maximum sequence length 4,096, and a minimum of 14 supervised tokens after
prefix truncation. It contains 1,339,867 accepted conversations;
`online_rejected.jsonl` records the remaining 9,993 filtered conversations.
Together they cover all 1,349,860 source IDs exactly once. The merged source
SHA256 recorded by the completion marker is
`59c742412dfc2a0f5989dbd244c503d32e0d82a576c3a42bae14bcd5a994b6eb`.
